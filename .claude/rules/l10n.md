# Localization

`.arb` files live under [lib/core/l10n/generated/](../../lib/core/l10n/generated/),
generated by `flutter gen-l10n` (auto-run on build, `generate: true`). Config in
[l10n.yaml](../../l10n.yaml); untranslated keys land in `untranslated_messages.txt`.

Add every key to **both** `app_en.arb` and `app_ar.arb`. Placeholders need an `@key`
block.

Localization includes a hand-written Kurdish delegate
([lib/core/l10n/kurdish/](../../lib/core/l10n/kurdish/)) layered on top of the generated
`AppLocalizations`.
