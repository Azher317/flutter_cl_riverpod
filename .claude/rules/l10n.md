# Localization

`.arb` files live under [lib/l10n/arb/](../../lib/l10n/arb/). The Dart code is
generated into `lib/core/l10n/generated/`, which is **not committed**: `flutter pub get`,
`flutter run` and `flutter gen-l10n` rebuild it (`generate: true`), and the
post-checkout hook does it after a branch switch. Config in
[l10n.yaml](../../l10n.yaml); untranslated keys land in `untranslated_messages.txt`.

Add every key to **both** `app_en.arb` and `app_ar.arb`. Placeholders need an `@key`
block.

Localization includes a hand-written Kurdish delegate
([lib/core/l10n/kurdish/](../../lib/core/l10n/kurdish/)) layered on top of the generated
`AppLocalizations`.
